# 🚗 RentWheelsX

RentWheelsX is a smart vehicle-sharing platform that allows users to rent cars and bikes from nearby owners. It helps vehicle owners earn money from idle vehicles while providing affordable ride options to users.

---

## 🌟 Features

* 🔍 Search and browse nearby vehicles
* 🚗 Rent cars and bikes easily
* 🔐 Secure user authentication
* 📊 Dashboard for vehicle owners
* 💰 Cost-effective rental system

---

## 🛠️ Tech Stack

### 🎨 Frontend

* React.js
* Vite
* Tailwind CSS

### ⚙️ Backend

* Java Spring Boot

### 🗄️ Database

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/RentWheelsX.git
cd RentWheelsX
```

### 2️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3️⃣ Backend Setup (Spring Boot)

```bash
cd backend
mvn spring-boot:run
```

### 4️⃣ Database Setup

* Install PostgreSQL
* Create a database (e.g., `rentwheelsx`)
* Update `application.properties` with your DB credentials

---

## 🔗 API Integration

* Backend runs on: `http://localhost:8080`
* Frontend connects via Axios
